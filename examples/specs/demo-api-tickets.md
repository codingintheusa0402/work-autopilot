# demo-api-tickets — 자동화 명세 · 데모 / SYNTHETIC

## 1. 목적 — 2일 넘게 지연된 주문은 고객센터 티켓으로 관리해야 함.
## 2. 트리거 — 평일 10:30.
## 3. 입력 — 주문 시스템 API `GET /orders` (토큰은 사용자가 환경변수 WA_APP_TOKEN 에 직접 설정).
## 4. 단계 — 주문 조회 → days_late > 2 필터 → 보고서 CSV → 지연 주문마다 티켓 생성.
## 5. 완료 기준 — `late_orders.csv` 에 지연 주문 목록, 티켓 시스템에 주문당 티켓 1건.
## 6. 예외 — 토큰 없으면 종료(코드 2). API 오류면 실패로 기록. 지연 0건이면 보고서만.
## 7. 사람 판단 — 없음.
## 8. 승인 — 메시지: 아니오 · 결제/구매: 아니오 · 삭제: 아니오 · 외부 제출: 예 (티켓 생성 = submit_form)
## 9. 로그인 — API 토큰은 사용자가 직접 발급·설정. 코드/파일에 저장하지 않음.
## 10. 실패하면 — 로그 + 대시보드.
## 11. 도구 — app-api. 회당 8분 절약.
