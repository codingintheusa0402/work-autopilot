# demo-browser-orders — 자동화 명세 · 데모 / SYNTHETIC

## 1. 목적 — 거래처 주문을 ERP 에 등록해야 출고가 시작됨.
## 2. 트리거 — 평일 09:45, 또는 직접 실행.
## 3. 입력 — `demo_files/orders.csv` (order, customer, qty). 가짜 데이터.
## 4. 단계 — ERP 주문 화면 열기 → 주문번호·거래처·수량 입력 → 미리보기 확인 → '등록'.
## 5. 완료 기준 — 주문마다 ERP 에 '등록완료 <주문번호>' 가 뜨고, `erp_entered.csv` 에 한 줄씩 기록.
## 6. 예외 — CSV 가 비면 종료. 로그인이 풀리면 실패로 기록하고 멈춤 (비밀번호 입력 안 함).
## 7. 사람 판단 — 없음.
## 8. 승인 — 메시지: 아니오 · 결제/구매: 아니오 · 삭제: 아니오 · 외부 제출: 예 ('등록' 클릭 = submit_form)
## 9. 로그인 — 사용자가 별도 자동화용 Chrome 프로필에서 직접 로그인 (데모 ERP 는 로그인 없음).
## 10. 실패하면 — 로그 + 대시보드.
## 11. 도구 — browser-cdp (API 없는 웹 시스템). 회당 12분 절약.
