# demo-invoice-sorter — 자동화 명세 (spec) · 데모 / SYNTHETIC

관련 작업: T13 파일·PDF 정리 (Finder · downloads), T11 Preview · invoice PDF, T14 Finder · 거래명세서 폴더
주당 소요 (관찰): 약 1.7시간 (합성 데이터)

## 1. 목적 — 이 일을 왜 하나요?
월말 정산 때 회계 담당이 거래처별 폴더에서 명세서를 찾습니다. 폴더가 정리돼 있어야 합니다.

## 2. 언제 시작하나요? (트리거)
평일 13:30, 하루 한 번. 직접 실행도 가능.

## 3. 입력 — 무엇을 보고 시작하나요?
다운로드 폴더의 `Invoice_<번호>_<거래처>.pdf` 파일. 다른 이름의 파일은 건드리지 않습니다.

## 4. 단계 — 지금 손으로 하는 순서
관찰된 순서 T13 → T11 → T14 가 맞음. 1) 다운로드 폴더 열기 2) PDF 를 열어 거래처 확인(파일명에 이미 있음)
3) `거래명세서/<거래처>/<YYYY-MM>/` 로 옮기기 4) 월별 요약 표 갱신.

## 5. 완료 기준 — '끝났다'는 어떻게 아나요?
다운로드 폴더에 규칙에 맞는 PDF 가 0개, 각 파일이 거래처/월 폴더에 있고 `summary-<YYYY-MM>.csv` 에 한 줄씩 있음.

## 6. 예외 상황
- 이름 규칙 밖 파일: 그대로 두고 로그에 이름만 남김.
- 같은 파일이 이미 있으면: 덮어쓰지 않고 건너뜀.
- 폴더가 없으면: 할 일 없음으로 정상 종료.

## 7. 사람 판단이 필요한 지점
없음 (파일명 규칙이 명확). 규칙 밖 파일은 사람이 봄.

## 8. 승인이 필요한 동작 (하나씩 명시)
- 메시지/메일 보내기: 예 — 팀 채널에 "N건 정리 완료" 1줄 (데모에서는 화면 출력만)
- 결제·구매: 아니오
- 삭제: 아니오 (이동만, 되돌리기 가능)
- 외부 시스템에 제출/확정: 아니오
→ '예' 인 동작도 사용자가 `wa approve demo-invoice-sorter send_message` 로 직접 승인해야 실제로 실행됩니다.

## 9. 로그인·계정
필요 없음 (로컬 파일만).

## 10. 실패하면
로그 + 대시보드의 '최근 실패'에 표시.

## 11. 도구 선택 (에이전트가 채움)
- 방식: script (파일 이동은 브라우저/AI 가 필요 없음)
- 이유: 규칙이 파일명에 다 있음 → 가장 단순하고 빠르고 확실한 방법
- 예약: 평일 13:30
- 회당 절약 시간(분): 18
